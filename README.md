# Онлайн-запись для барбершопа

Готовый сайт записи для салона: клиент выбирает услугу, мастера и время с телефона,
мастер сразу получает уведомление в Telegram, владелец управляет расписанием в админке.

- **Страница записи** `/` — 4 шага, «любой мастер», ближайшее свободное время, «Мои записи» с отменой, добавление в календарь.
- **Админка** `/admin` — записи по дням с телефонами и выручкой, ручная запись по звонку, перерывы, настройки салона (услуги, цены, мастера, график, выходные, праздники).
- **Telegram** — уведомления о новых записях и отменах в общий чат салона и лично мастеру.
- **Без двойных записей** — время блокируется атомарно в Redis, даже если два клиента жмут одновременно.
- Без зависимостей и сборки: чистый Node.js 18+ и статичные HTML-страницы.

## Запуск у себя

```bash
npm run dev     # http://localhost:3000, админка: /admin, пароль: admin
npm test        # интеграционные тесты API
```

Локально данные хранятся в `.data/db.json`.

## Запуск для салона (Vercel, бесплатно)

1. Импортируйте репозиторий на [vercel.com/new](https://vercel.com/new). Framework Preset — **Other**, остальное по умолчанию.
2. **Хранилище:** в проекте откройте Storage → Create → **Upstash for Redis** (бесплатный план) и подключите к проекту.
   Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.
3. **Пароль админки:** Settings → Environment Variables → `ADMIN_PASSWORD` = надёжный пароль.
4. **Telegram** (по желанию):
   - создайте бота у [@BotFather](https://t.me/BotFather) → `TELEGRAM_BOT_TOKEN`;
   - добавьте бота в чат салона, напишите в чат любое сообщение и откройте
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — значение `chat.id` → `TELEGRAM_CHAT_ID`;
   - мастеру для личных уведомлений: он пишет боту `/start`, его `chat.id` указывается в админке.
5. Сделайте Redeploy, откройте `/admin`, заполните данные салона и нажмите «Проверить Telegram».
6. Свой домен: Settings → Domains.

Если Redis не подключён, админка покажет предупреждение — без него записи на Vercel не сохраняются.

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `ADMIN_PASSWORD` | да | пароль для `/admin` |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | да (на Vercel) | Upstash Redis; также принимаются `UPSTASH_REDIS_REST_URL/TOKEN` |
| `TELEGRAM_BOT_TOKEN` | нет | токен бота |
| `TELEGRAM_CHAT_ID` | нет | общий чат салона |

## Устройство

```
public/index.html   страница записи
public/admin.html   админка
api/                serverless-функции Vercel (config, slots, bookings, cancel, admin)
lib/core.js         расписание, слоты, запись/отмена, блокировки
lib/store.js        Upstash Redis REST или локальный JSON-файл
lib/notify.js       Telegram
server.js           локальный сервер для разработки
```

Один деплой = один салон. Для нового клиента — новый проект Vercel из этого же репозитория.
